# Molecular Computation and Design Lab website

Static website for the Molecular Computation and Design Lab at IIT Gandhinagar.

## Student portraits

Upload `khushbu-chaudhary.jpg` and `arnav-lasod.jpg` (JPEG images) to the repository root, alongside `members.html`. The reserved circular portrait spaces display “Photo forthcoming” until the files are available. No HTML changes are needed when uploading images with these filenames. Use square portraits for the best crop.

The M.Tech. student welcome announcement is dated 4 November 2026 (posting date) in `updates-data.js`, which supplies both the homepage and Updates archive.
